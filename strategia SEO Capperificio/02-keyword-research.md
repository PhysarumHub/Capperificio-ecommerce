## Mappa keyword → contenuti (priorità di pubblicazione)

```
PRIORITÀ 1 (subito, alto ROI):
  • Pillar "Cappero di Racale"            → cluster 1 + 2
  • Guida "Calibri del cappero"           → cluster 2
  • 7 schede prodotto ottimizzate         → cluster 1
  • Landing Ho.Re.Ca                       → cluster 5
  • SA "come dissalare i capperi"          → cluster 3 (alto volume pratico)
  • SA "sostituto dei capperi"             → cluster 3 (intercetta domanda)

PRIORITÀ 2 (settimane 4–12, motore programmatico):
  • 20-30 pagine ricette                   → cluster 4
  • SA informazionali (capperi vs cucunci, conservazione, benefici) → cluster 3
  • Hub abbinamenti                        → cluster 3/4

PRIORITÀ 3 (mese 3+):
  • Espansione ricette (50-150 pagine)     → cluster 4
  • Pagine regalo/stagionali               → cluster 6
  • Pagine territorio/storia               → E-E-A-T
```

## Come fare la keyword research operativa (passi)

1. **Seed**: parti dalle keyword di questo file + nomi prodotto.
2. **Espansione**: Keyword Planner, "Ricerche correlate", "People also ask", autocomplete Google, AnswerThePublic, sezione commenti/forum (Gennarino, Reddit r/italyfood).
3. **AI mining**: chiedi a ChatGPT/Perplexity «quali domande fanno le persone sui capperi?» → ottieni le query che gli LLM associano all'entità (utile per AEO).
4. **Validazione volume/difficoltà**: Ahrefs/Semrush (anche trial) o Keyword Surfer (free).
5. **Clustering**: raggruppa per intent e per pagina di destinazione (1 pagina = 1 cluster di intent, non 1 keyword).
6. **Prioritizza**: `(volume × intent commerciale) / difficoltà`. Privilegia coda lunga a bassa difficoltà all'inizio.
